# PDF Manifest — every PDF that was on DreamHost

**Purpose:** a complete hunting list. 51 PDFs lived in `ashleypimenta.com/wp-content/uploads/`.
19 are saved in this repo. 31 were never pulled off and are gone once the DreamHost account closes.
This file is so those 31 can be found on the external hard drive later.

**Written:** 2026-08-10, before cancelling DreamHost.

**The folder path is a date clue, not a real location.** WordPress filed uploads as
`uploads/YYYY/MM/`, based on **when the file was uploaded to the site**, not when the work was made.
So `2025/09` means "uploaded September 2025," and the CNN debate boards in it are from the 2024
election cycle. On the external drive these will be in project folders, not year folders.
